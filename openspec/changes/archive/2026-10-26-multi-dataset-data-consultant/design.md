# Design

Клиент передаёт `datasetSlugs` как непустой уникальный список. Сервер разрешает каждый slug через реестр. На одном ходе агент видит схемы всех прикреплённых датасетов. Инструменты `sample_rows` и `execute_sql` принимают `datasetSlug`; запрос исполняется только внутри выбранного датасета с прежней защитой от записи и ограничением результата. Это работает и при разных подключениях.

Агент выполняет хотя бы один SQL-запрос к каждому прикреплённому датасету, прежде чем закончить сравнительный ответ. Результаты сохраняются как отдельные доказательства с именем источника, SQL, таблицей и признаком обрезки. Агент сопоставляет показатели только при сравнимых ключах, единицах измерения и периодах; неподтверждённые объяснения называет гипотезами и предлагает способ проверки. Единый SQL JOIN между разными серверами не создаётся.

Один датасет продолжает работать по прежнему контракту. История нового формата содержит `datasetSlugs` и `datasetTitles`; старые ходы с `datasetSlug` остаются читаемыми.
