# Proposal: multi-dataset-data-consultant

## Why

Чат консультанта принимает один датасет за ход. Сотрудник не может задать сравнительный вопрос и получить обоснованные гипотезы по нескольким подготовленным наборам данных.

## What Changes

- В чате разрешить прикреплять несколько датасетов через `@`.
- Агенту дать схему и инструменты чтения каждого прикреплённого датасета.
- Требовать наблюдения из каждого источника перед сравнительным ответом и показывать доказательства и осторожно сформулированные гипотезы по источникам.
- Сохранять список источников каждого хода в истории.

## Capabilities

### Modified Capabilities

- `agent` — многоисточниковый анализ и проверяемые гипотезы.
- `web-ui` — множественное прикрепление и показ источников ответа.
