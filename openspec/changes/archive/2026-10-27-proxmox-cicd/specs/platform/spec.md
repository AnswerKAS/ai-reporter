## MODIFIED Requirements

### Requirement: Доставка на сервер
После каждого push в `main` GitHub Actions SHALL проверять тесты бэкенда,
lint и сборку фронтенда и валидность OpenSpec. Сервис в LXC 111 SHALL
доставлять только точный коммит `main`, для которого соответствующий workflow
события `push` завершился успешно. Доставка SHALL сохранять серверные `.env`,
Docker-тома и загруженные артефакты, проверять `/api/health` и восстанавливать
предыдущий исходный код при ошибке. GitHub Actions не требует доступа к
приватной сети Proxmox или секретов сервера.

#### Scenario: Проверки не прошли
- **WHEN** workflow завершился неуспешно или ещё идёт
- **THEN** сервер не доставляет этот коммит

#### Scenario: Успешный push в main
- **WHEN** workflow события push для текущего SHA main завершился успешно
- **THEN** сервер обновляет backend и frontend, не изменяя Langfuse и данные

#### Scenario: Загруженные данные на сервере
- **WHEN** выполняется доставка новой версии
- **THEN** файлы `.env`, Docker-тома и загруженные CSV остаются на месте

#### Scenario: Неуспешная новая версия
- **WHEN** сборка или проверка здоровья завершается ошибкой
- **THEN** сервер восстанавливает предыдущий исходный код и сообщает ошибку
