# Proposal: dataset-chat-markdown

## Why

Ответ консультанта сейчас выводится как обычный текст. Списки, выделения, ссылки, код и таблицы Markdown видны пользователю с исходными символами разметки.

## What Changes

- Отображать Markdown в ответах консультанта во время потоковой генерации и в сохранённой истории.
- Поддержать обычный Markdown и таблицы GitHub Flavored Markdown, сохранив безопасный вывод текста модели.

## Capabilities

### Modified Capabilities

- `web-ui` — оформление ответов консультанта по данным.
