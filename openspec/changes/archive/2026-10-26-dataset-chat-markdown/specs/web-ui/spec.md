## MODIFIED Requirements

### Requirement: Потоковый чат вопросов
Рабочее окно SHALL показывать сообщения пользователя и агента в одной прокручиваемой ленте, восстанавливать сохранённую историю и отправлять сообщение по Enter; Shift+Enter SHALL вставлять новую строку. Ответ агента SHALL отображать Markdown одинаково во время потока и после загрузки истории, включая заголовки, списки, таблицы и блоки кода; исходный HTML SHALL оставаться неисполняемым текстом.

#### Scenario: Агент отвечает
- **WHEN** сотрудник отправляет вопрос клавишей Enter
- **THEN** реплика сразу появляется в ленте, а ответ и состояния агента появляются по мере поступления с форматированием Markdown

#### Scenario: История с Markdown
- **WHEN** сотрудник открывает сохранённый чат с таблицей и блоком кода в ответе
- **THEN** таблица и код отображаются как элементы Markdown, без исполнения HTML из ответа
