# Design

Ответы консультанта рендерит отдельный React-компонент на основе `react-markdown` и `remark-gfm`. Один компонент используется для завершённых и потоковых ответов. Для заголовков, списков, цитат, кода, ссылок и таблиц задаются стили из токенов текущей темы. Широкие таблицы и длинные строки кода прокручиваются внутри ответа.

Исходный HTML не интерпретируется. Ссылки проходят встроенную проверку допустимых адресов `react-markdown`; изображения модели не загружаются. Текст в базе и API остаётся исходной строкой Markdown, поэтому старые диалоги отображаются новым способом без миграции.
