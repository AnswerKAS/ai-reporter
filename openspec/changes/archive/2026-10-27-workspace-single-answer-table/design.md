# Design

Последний успешный SQL-результат каждого источника уже входит в проверенный ответ. Промпт направляет модель к итоговому результату, отвечающему на вопрос. Для одного датасета текстовый ответ остаётся без Markdown-таблицы; при сравнении разных подключений модель может дать одну сводную Markdown-таблицу.

На клиенте правило применено и к новым, и к сохранённым сообщениям. Markdown-рендер показывает первую таблицу, а последующие помещает в раскрываемые блоки. Если Markdown-таблица есть, SQL-результаты доступны отдельно. Если её нет, виден итоговый SQL-результат, а остальные результаты свернуты. Формулировки с явной просьбой о нескольких отдельных таблицах сохраняют несколько видимых результатов. Все проверенные строки и SQL остаются доступными.
