# Proposal: workspace-single-answer-table

## Why

Один вопрос в рабочем чате может показывать сразу несколько таблиц: модель добавляет их в Markdown, а интерфейс отдельно выводит результаты SQL. Предыдущая правка скрывала SQL-результат только при наличии Markdown-таблицы и не ограничивала число таблиц самого ответа или нескольких источников.

## What Changes

- Агент готовит один итоговый SQL-результат по одному датасету и не повторяет его таблицей в тексте ответа.
- Интерфейс показывает одну таблицу по умолчанию; дополнительные Markdown-таблицы и результаты SQL доступны через раскрываемые блоки.
- Явный запрос на несколько отдельных таблиц показывает их сразу.

## Capabilities

### Modified Capabilities

- `agent` — выбор итогового результата для ответа по данным.
- `web-ui` — число одновременно видимых таблиц в рабочем чате.
