## ADDED Requirements

### Requirement: Одна видимая таблица ответа по умолчанию
Рабочий чат SHALL показывать одну таблицу для одного вопроса, если сотрудник явно не попросил несколько отдельных таблиц. Дополнительные Markdown-таблицы и проверенные SQL-результаты SHALL оставаться доступными по раскрытию. Правило SHALL работать во время потокового ответа и после восстановления истории.

#### Scenario: Несколько таблиц в Markdown
- **WHEN** ответ агента содержит несколько Markdown-таблиц без явной просьбы о них
- **THEN** видна первая таблица, а остальные доступны по раскрытию

#### Scenario: Несколько результатов SQL
- **WHEN** ответ не содержит Markdown-таблицы, но приложены результаты нескольких источников
- **THEN** виден один итоговый результат, а остальные доступны по раскрытию

#### Scenario: Явная просьба о нескольких таблицах
- **WHEN** сотрудник просит две или несколько отдельных таблиц
- **THEN** запрошенные таблицы показываются сразу
