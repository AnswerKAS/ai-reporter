# Proposal: dataset-sql-only-create

## Why

Форма «Новый датасет» требует выбрать тип источника, способ чтения и slug, хотя тип уже задан подключением, а для таблицы можно написать `SELECT`. Эти решения мешают администратору быстро завести подготовленный датасет.

## What Changes

- В форме остаются подключение, название, описание и обязательный SQL-запрос.
- Тип источника берётся из выбранного подключения; CSV и отдельный ввод таблицы из формы исключаются.
- Slug остаётся внутренним идентификатором API, но создаётся автоматически из названия с учётом занятых slug.
- У подключений есть уникальные видимые имена (`title`) в `DB_CONNECTIONS`; старые записи без имени временно отображаются по ключу.

## Capabilities

### Modified Capabilities

- `datasets` — упрощённое создание SQL-датасета и алиасы подключений.

## Impact

Меняются форма админки, проверка конфигурации и примеры настройки. Существующие датасеты на таблицах и CSV продолжают читаться и редактироваться. Контракт API создания сохраняется для совместимости.
