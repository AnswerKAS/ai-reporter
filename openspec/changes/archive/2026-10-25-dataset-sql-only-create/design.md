# Design: dataset-sql-only-create

Форма загружает список `/api/datasets/connections`, исключающий метабазу. В выпадающем списке показаны уникальный `title` и тип. Выбранная запись даёт `connectionKey` и `source` запросу создания. Для объекта базы администратор вводит `SELECT * FROM ...` в единственное SQL-поле.

Slug нужен как ключ датасета в ссылках, отчётах и словаре, поэтому удаляется только из формы. Клиент транслитерирует название через существующий `suggestSlug`, а если slug занят, добавляет числовой суффикс в пределах 40 символов. API продолжает проверять уникальность и вернёт 409 при конкурентном создании.

`DB_CONNECTIONS` принимает `title` как видимое имя подключения. Проверка конфигурации отклоняет пустые и повторяющиеся имена без вывода DSN. Записям старых установок без `title` подставляется ключ для совместимости; миграция записывает такое имя в JSON. Создание CSV и по имени таблицы из интерфейса закрыто, но старые датасеты и API-контракт остаются рабочими.
