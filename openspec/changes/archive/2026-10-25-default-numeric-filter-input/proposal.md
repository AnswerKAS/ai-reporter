## Why

Для числового разреза конструктор по умолчанию создаёт список значений. Отдельный режим ввода числа уже поддержан, но назван «Точное число» и не виден сразу после добавления фильтра.

## What Changes

- Называть отдельный режим фильтра «Число».
- При добавлении фильтра по числовому разрезу выбирать этот режим по умолчанию.
- Принимать десятичные значения в числовом поле.
- Сохранить переключение на список и диапазон.
