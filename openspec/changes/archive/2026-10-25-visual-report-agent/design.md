# Design: visual-report-agent

Агент конструктора использует существующий LangGraph ReAct цикл. Инструменты `get_vocabulary` и `get_datasets` раскрывают доступные данные, `preview_report` валидирует полное определение и исполняет каждую секцию через `reports.executor.build_section` с небольшим лимитом строк. До успешного предпросмотра финальное предложение не принимается. Ошибка инструмента возвращается агенту для исправления.

Маршрут `/api/reports/chat/stream` передаёт NDJSON события `status`, `delta`, `done`, `error`, записывает завершённый ход в существующее хранилище диалогов. Клиент показывает прогресс в том же модальном диалоге, затем применяет определение к конструктору. Сохранение отчёта остаётся явным действием после предпросмотра.

В отсутствие модели действующий парсер и генератор вариантов выбирают первый подходящий вариант на сервере. Старый маршрут рекомендаций остаётся совместимым для существующих клиентов, но новый интерфейс его не вызывает.
