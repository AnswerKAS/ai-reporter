# Proposal: visual-report-agent

## Why

Чат конструктора показывал готовые варианты по датасету и не проверял словарные карточки перед предложением. Вопросы по датасету также вели к отдельному предложению «Собрать отчёт», смешивая разовый анализ и постоянный отчёт.

## What Changes

- LangGraph-агент конструктора исследует словарь и датасеты, составляет полный визуальный отчёт и проверяет каждую карточку на данных.
- Диалог конструктора передаёт прогресс и ответ потоком, сохраняет переписку и применяет проверенную раскладку к предпросмотру.
- Готовые варианты не показываются в чате конструктора; разовый ответ по датасету больше не предлагает создать отчёт.
- Без модели парсер выбирает один конкретный вариант вместо списка для выбора.

## Capabilities

### Modified Capabilities

- `report-builder` — агент собирает и проверяет визуальную раскладку; предложения по датасету убраны из интерфейса.
- `nl-parsing` — потоковый ход агента конструктора и сохранение контекста.

## Impact

`backend/app/agent/runner.py`, `backend/app/api/reports.py`, `frontend/src/components/builder/ReportChat.tsx`, `frontend/src/components/DatasetQuestionPanel.tsx`, `frontend/src/pages/WorkspacePage.tsx`, тесты и спецификации.
