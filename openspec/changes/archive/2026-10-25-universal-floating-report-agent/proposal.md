# Proposal: universal-floating-report-agent

## Why

Отдельный разбор для конкретной фразы противоречит универсальному агенту. При ошибке предпросмотра агент терял собственный SQL, из-за чего повторял неудачные действия. Обязательный шаг выбора данных мешает сценарию, где датасет прикрепляется через `@`, а поля выбирает агент.

## What Changes

- Удалить частный шаблон ответа и отдельный режим «без модели» из чата конструктора.
- Передавать агенту действие и результат каждого инструмента, включая ошибочный SQL; дать ему общий инструмент образца строк.
- Открывать конструктор сразу на раскладке, показывать чат плавающей панелью справа внизу; ручной выбор данных оставить необязательной панелью.

## Capabilities

### Modified Capabilities

- `agent` — универсальный цикл анализа и исправления SQL.
- `report-builder` — раскладка сразу и плавающий чат.
- `nl-parsing` — нет отдельного режима без модели в чате конструктора.
