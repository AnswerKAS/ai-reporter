# Design

LangGraph сохраняет каждое действие вместе с ответом инструмента. После ошибки `preview_report` следующий шаг видит исходное определение и сообщение источника, а не только сообщение об ошибке. `get_datasets` возвращает прикреплённые источники; `sample_dataset` по запросу даёт несколько строк. SQL блоки по-прежнему проходят проверку режима чтения и живой предпросмотр.

На странице конструктора раскладка видна сразу. Чат остаётся смонтированным при сворачивании, чтобы не терять диалог и поток. Кнопка в правом нижнем углу открывает его. Ручной выбор датасетов и полей доступен из необязательного окна; он больше не является шагом перед раскладкой.
