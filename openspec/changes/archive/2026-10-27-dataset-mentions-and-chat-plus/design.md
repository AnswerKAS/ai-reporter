# Design

Поиск вынести в чистую функцию: разбить запрос по `_`, пробелам и дефисам,
сопоставить части с названием и slug без ограничения числа результатов. Меню
остаётся ограниченным по высоте и прокручивается.

Кнопка `+` вызывает существующий `POST /api/chats` без conversationId и с
названием «Новый чат». Этот endpoint уже создаёт пустой диалог и записывает
`saved_at`. После ответа меню обновляется и URL получает `chat=<id>`. Кнопку
«Сохранить чат» заменить на «Переименовать» для уже выбранного чата. Действие
`POST /api/chats/new` сохранить для совместимости API, но интерфейс его не
использует.
