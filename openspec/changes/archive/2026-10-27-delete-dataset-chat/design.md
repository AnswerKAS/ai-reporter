# Design

`DELETE /api/chats/{conversation_id}` принимает `kind` и `target`, проверяет
владельца и область чата, затем в одной транзакции удаляет сообщения и запись
диалога. Отсутствующий и чужой чат возвращают 404 без раскрытия данных.

В `ChatSidebar` кнопка удаления стоит рядом со ссылкой на чат, а не внутри неё.
`useConfirm` показывает название удаляемого чата. После успеха список
обновляется; при удалении выбранного чата URL получает id следующего
сохранённого диалога либо становится `/workspace`. Последний id в localStorage
очищается. Пустой маршрут не должен автоматически восстанавливать последний
диалог из базы, иначе удалённый чат незаметно заменится другим.
