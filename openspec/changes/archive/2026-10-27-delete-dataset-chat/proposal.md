# Удаление чата вопросов по данным

## Why

Сохранённые консультации можно создать и переименовать, но нельзя удалить.
Список постепенно заполняется ненужными диалогами.

## What Changes

- В боковом меню каждого чата появляется действие удаления с подтверждением.
- API удаляет только принадлежащий сотруднику чат вместе с сообщениями.
- После удаления открытого чата интерфейс переходит к другому сохранённому
  диалогу или показывает пустое состояние.
