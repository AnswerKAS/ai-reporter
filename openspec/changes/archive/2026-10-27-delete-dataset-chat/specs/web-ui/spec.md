## ADDED Requirements

### Requirement: Удаление чата в меню вопросов по данным
Список консультаций SHALL давать отдельное действие удаления каждого чата.
Перед удалением SHALL показываться подтверждение с названием. После удаления
выбранного чата интерфейс SHALL открыть другой сохранённый чат или пустое
состояние, не восстанавливая удалённый диалог.

#### Scenario: Удаление открытого чата
- **WHEN** сотрудник подтверждает удаление открытого чата
- **THEN** чат исчезает из меню и перестаёт быть активным

#### Scenario: Отмена
- **WHEN** сотрудник отменяет подтверждение
- **THEN** чат и его сообщения остаются доступны
