# Design

Левый `SidebarPanel` показывает `ChatSidebar` для режима вопросов по данным и прежний `ReportTree` для каталога отчётов. Меню чатов читает существующий `GET /api/chats?kind=dataset&target=workspace`, фильтрует список по названию и ведёт на `/workspace?chat=<id>`. Идентификатор в URL выбирает диалог в `DatasetQuestionPanel`; набор прикреплённых датасетов восстанавливается из его последнего хода. Сохранение посылает событие обновления меню без перезагрузки страницы.

В конструкторе удаляются кнопки именованного сохранения и перехода между сохранёнными чатами. Существующие серверные записи не удаляются. История продолжает автоматически сохраняться и открываться по цели отчёта. Переход к новому отчёту продолжает начинаться с чистого контекста.
