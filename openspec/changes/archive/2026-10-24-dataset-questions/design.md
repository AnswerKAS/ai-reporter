# Design: dataset-questions

На каждом ходе клиент передаёт вопрос и историю вопросов с проверенными планами. Модель видит схему и описание одного датасета, возвращает JSON с полями, агрегатами, фильтрами, группировкой и лимитом. Сервер принимает только известные поля и операции, привязывает значения параметрами, ограничивает результат 100 строками и вычисляет ответ из фактических данных. SQL доступен только администратору. CSV читается потоково с потолком 50 000 строк; более крупный файл требует переноса в СУБД. Для источников БД предусмотрен лимит выполнения 30 секунд.
