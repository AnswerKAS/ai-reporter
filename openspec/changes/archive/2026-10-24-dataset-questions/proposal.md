# Proposal: dataset-questions

## Why

Превью показывает первые строки, но пользователь не может спросить о числах во всём датасете и уточнить вопрос.

## What Changes

В карточке датасета появляется диалог. Модель возвращает структурированный план выборки по одному датасету; сервер проверяет его, строит запрос и показывает ответ из результата.

## Capabilities

### Modified Capabilities

- `datasets` — вопросы по данным и результаты.
- `web-ui` — диалог в карточке датасета.

## Impact

Новый `POST /api/datasets/{slug}/ask` для авторизованных пользователей, без хранения истории на сервере.
