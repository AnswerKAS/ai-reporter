## MODIFIED Requirements

### Requirement: Разделение прав по ролям
Любой авторизованный пользователь SHALL просматривать датасеты, их схемы и превью, создавать отчёт из проверенного определения и читать свои отчёты. Автор SHALL менять название, описание, метки, фильтры и определение своего отчёта без назначения. Читатель с доступом SHALL менять название, описание и фильтры, но не определение и не метки. Администратор SHALL управлять удалением отчётов, назначениями доступа, датасетами и словарём. Только администратор SHALL назначать разрешённые метки пользователям и группам.

#### Scenario: Пользователь создаёт отчёт
- **WHEN** сотрудник сохраняет проверенное определение из рабочего окна
- **THEN** отчёт создаётся с ним как автором и сразу доступен ему

#### Scenario: Пользователь смотрит датасеты
- **WHEN** обычный пользователь открывает выбор датасета в рабочем окне
- **THEN** он видит подготовленные данные и может задавать вопросы, но не может менять датасет

#### Scenario: Читатель меняет метки отчёта
- **WHEN** читатель с назначением, не являющийся автором, отправляет новые метки
- **THEN** API возвращает 403 и аудитория отчёта не меняется

#### Scenario: Читатель правит чужое определение
- **WHEN** читатель с доступом к чужому отчёту пытается изменить его определение
- **THEN** система возвращает 403
