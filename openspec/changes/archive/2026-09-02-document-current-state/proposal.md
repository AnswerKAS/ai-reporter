# Proposal: document-current-state

## Why

Проект быстро растёт (отчёты, датасеты, черновики скиллов, права), но поведение системы живёт только в коде и AGENTS.md. OpenSpec внедряется в проект: чтобы дельты будущих изменений имели базу, фиксируем текущее состояние ключевых возможностей как стартовые спеки. Это единственный намеренный акт бэкфилла — дальше спеки растут только от реальных изменений.

## What Changes

- Добавляются 6 стартовых спецификаций возможностей, описывающих **уже существующее** поведение системы (без изменений кода):
  - `reports` — сборка отчётов по скиллам: воркер, режимы auto/demo/llm, ReportSpec, фильтры, realtime-обновление, детализация по клику, комбо-графики.
  - `datasets` — реестр датасетов: источники ClickHouse/PostgreSQL/CSV, DSN-ссылки (`env:VAR`, `app:postgres`), вычитка схемы, превью, маскирование секретов в ошибках.
  - `skills` — скилл-файлы отчётов: доменная структура `домен/имя`, служебные файлы `_`, правила каркаса (opencode-скилл report-skill), перекомпиляция.
  - `skill-drafts` — черновики скиллов: генерация агентом по описанию, отказ `unavailable` при недостатке данных, проверка правилом-ревьюером, публикация с созданием отчёта и выдачей доступа автору.
  - `access-control` — аутентификация (pbkdf2, Bearer-сессии), пользователи/группы, назначения отчётов, дефолтный админ.
  - `artifacts` — хранилище артефактов: фасад `services/storage.py`, local-режим с `ARTIFACTS_DIR`, подготовка к S3.
- Код проекта не меняется: change чисто документационный, фиксирует поведение as-is.

## Capabilities

### New Capabilities

- `reports` — жизненный цикл отчёта и его рендеринг (specs/reports/spec.md)
- `datasets` — реестр источников данных (specs/datasets/spec.md)
- `skills` — скилл-файлы отчётов (specs/skills/spec.md)
- `skill-drafts` — генерация и модерация скиллов (specs/skill-drafts/spec.md)
- `access-control` — пользователи, группы, доступы (specs/access-control/spec.md)
- `artifacts` — хранилище артефактов (specs/artifacts/spec.md)

### Modified Capabilities

- (пусто — стартовая документация, существующие спеки отсутствуют)

## Impact

- Затрагивается только `openspec/` (новые файлы) и `AGENTS.md` (раздел про spec-driven workflow).
- Код, API, БД — без изменений.
- После archive: `openspec/specs/` содержит стартовые спецификации, на которые будут опираться дельты будущих изменений.
