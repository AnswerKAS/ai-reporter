# Proposal: report-chat-dataset-mentions

## Why

Сотрудник получает отказ на просьбу сравнить лучших и худших продавцов и показать динамику отставания. Чат конструктора не позволяет явно приложить датасет к сообщению; запасной разбор по словарю может обращаться к модели и не умеет составлять такой аналитический отчёт.

## What Changes

- В чате конструктора `@` открывает поиск датасетов, выбранные источники видны перед отправкой и передаются агенту как явное ограничение.
- Агент самостоятельно изучает поля прикреплённых датасетов и строит проверенные SQL-блоки для аналитических запросов; сотруднику не нужно заранее выбирать поля.
- Разбор «без модели» действительно обходит модель и для типового сравнения лучших и худших сотрудников с динамикой разницы собирает отчёт из схемы датасета.

## Capabilities

### Modified Capabilities

- `agent` — анализ прикреплённых датасетов и проверка созданного SQL-отчёта.
- `report-builder` — прикрепление датасета через `@` в диалоге.
- `nl-parsing` — предсказуемый разбор указанного аналитического сценария без модели.
