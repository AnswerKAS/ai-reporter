# Design

Прикреплённые через `@` slugs передаются отдельно от датасетов, выбранных на шаге «Данные». Сервер проверяет их наличие в каталоге и требует, чтобы SQL-блоки итогового отчёта ссылались на прикреплённый источник. Агент получает схему, названия полей и типы, затем проверяет результат через существующий `preview_report`.

Запасной разбор принимает флаг `withoutModel`. Для запроса о лучших/худших сотрудниках и динамике отставания он ищет в схеме поля сотрудника, даты и числового показателя продаж. Если однозначного набора нет, сообщает, чего именно не хватает. Составляет SQL с оконным ранжированием и ежедневной разницей между первым и последним сотрудником по сумме показателя. Исходные данные только читаются.
