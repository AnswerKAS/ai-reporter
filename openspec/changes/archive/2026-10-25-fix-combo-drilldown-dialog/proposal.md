## Why

У комбинированного графика клик по кривой линии не открывает детализацию: обработчик серии вызывается только для точки, а обработчик графика не подключён. Окно сырых строк также слишком мало для таблицы.

## What Changes

- Подключить обработчик клика по области комбинированного графика с поиском ближайшей точки оси.
- Сохранить точную детализацию по серии при клике по её точке и избежать повторного открытия окна.
- Увеличить окно детализации примерно до 75% площади экрана и дать таблице занять доступную высоту.
