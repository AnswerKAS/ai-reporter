# Proposal: workspace-dataset-overview

## Why

В режиме вопросов рабочего окна сотрудник видит только название выбранного датасета. Без списка полей и примеров значений ему трудно сформулировать вопрос по доступным данным.

## What Changes

- Рабочее окно сразу показывает поля выбранного датасета с понятными названиями, типами и ролями.
- Под полями показываются несколько настоящих строк источника; полный список полей и превью открываются в окне с сортировкой и фильтрами.
- Детали загружаются только для выбранного датасета через существующий API. Ошибка или пустое превью не закрывают форму вопроса.

## Capabilities

### Modified Capabilities

- `web-ui` — обзор данных перед вопросом в едином рабочем окне.

## Impact

Фронтенд: `WorkspacePage`, новый `DatasetOverview`, существующие `fetchDataset`, `DatasetPreviewTable`, `Modal`. Новых методов API и изменений хранения нет.
