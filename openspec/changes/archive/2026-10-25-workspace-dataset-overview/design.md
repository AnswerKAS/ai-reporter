# Design: workspace-dataset-overview

## Данные

Список датасетов уже содержит поля и настройки. После выбора одного датасета компонент запрашивает `GET /api/datasets/{slug}` для превью. При смене датасета компонент размонтируется по ключу `slug`, а прежний ответ запроса игнорируется после очистки эффекта.

## Представление

Над формой вопроса показываются первые восемь полей и первые четыре строки. Это даёт контекст без длинной прокрутки. Кнопка «Все поля и строки» открывает существующую интерактивную таблицу 50 строк и полный перечень полей. Вопрос остаётся доступен при ошибке загрузки строк.

Техническое имя поля доступно рядом с человеческим названием. Адрес и параметры подключения не показываются. Горизонтальная прокрутка ограничена самой таблицей, чтобы страница оставалась удобной на узком экране.
