## ADDED Requirements
### Requirement: Основной результат ответа
Интерфейс SHALL показывать основной SQL-результат из `primaryDatasetSlug`, а прочие результаты SHALL сворачивать, если несколько таблиц явно не запрошены. Для старых ответов без этого поля SHALL использоваться первый результат. Определение Markdown-таблиц SHALL соответствовать GFM-рендеру, включая одну колонку и вложенность. Количество объектов или просьба об отдельной таблице в единственном числе SHALL не разрешать несколько видимых таблиц.

#### Scenario: Сохранённый ответ по школам
- **WHEN** старый ответ содержит итог по школам и следующую за ним выборку занятий
- **THEN** виден итог по школам, а выборка доступна по раскрытию

#### Scenario: Одна колонка Markdown
- **WHEN** ответ содержит таблицу с одной колонкой и SQL-результат
- **THEN** таблица Markdown видна, а SQL-результат свёрнут

#### Scenario: Количество школ
- **WHEN** пользователь просит три школы в одной таблице
- **THEN** показывается одна таблица
