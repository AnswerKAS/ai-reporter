Поле `primaryDatasetSlug` указывает на последний проверенный результат выбранного датасета. Сервер принимает только прикреплённый источник и использует первый источник при отсутствии поля для совместимости. Клиент применяет тот же выбор и сворачивает остальные результаты независимо от их положения. Сохранённые ответы без поля также используют первый результат. Для Markdown используется unified + remark-parse + remark-gfm, как при рендере react-markdown, включая таблицы с одной колонкой и вложенные таблицы. Явные числительные относятся непосредственно к слову «таблицы», а не к школам или другим объектам.
