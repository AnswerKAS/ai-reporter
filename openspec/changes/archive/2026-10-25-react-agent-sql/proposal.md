## Why

Диалоги о датасете и новом отчёте сейчас работают независимо и не могут проверить промежуточный результат. Вопросы по данным ограничены небольшим набором агрегатов, поэтому оконные функции и сложные аналитические запросы недоступны.

## What Changes

- Оба диалога используют ReAct граф на LangGraph с явными инструментами и проверкой результата.
- Агент вопросов получает схему, пробу данных и выполняет произвольный запрос чтения, включая CTE и оконные функции.
- Сервер проверяет один оператор чтения, включает режим чтения источника и ограничивает время выполнения и объём ответа.
- Агент отчёта получает словарь и инструменты проверки определения перед предложением пользователю.
- Интерфейс показывает объяснение расчёта и SQL по нажатию.
- Диалоги сохраняются в PostgreSQL с привязкой к сотруднику; вопрос к датасету получает потоковый чат с отправкой по Enter.

## Capabilities

### New Capabilities

- `agent`: цикл инструментов, наблюдений и итогового ответа в диалогах.

### Modified Capabilities

- `datasets`: вопросы к датасету через произвольный аналитический SQL только для чтения.
- `nl-parsing`: создание отчёта через агент с проверкой определения.
- `web-ui`: показ SQL по нажатию и объяснения ответа.

## Impact

`backend/app/agent`, API вопросов и чата отчёта, адаптеры источников, тесты и компоненты обоих диалогов. Новые учётные данные не требуются.
