## ADDED Requirements

### Requirement: Прозрачность ответа по данным
Интерфейс SHALL показывать объяснение расчёта и раскрывать сгенерированный запрос по нажатию.

#### Scenario: Просмотр запроса
- **WHEN** сотрудник раскрывает SQL под ответом агента
- **THEN** он видит текст запроса к логической таблице датасета

### Requirement: Потоковый чат вопросов
Рабочее окно SHALL показывать сообщения пользователя и агента в одной прокручиваемой ленте, восстанавливать сохранённую историю и отправлять сообщение по Enter; Shift+Enter SHALL вставлять новую строку.

#### Scenario: Агент отвечает
- **WHEN** сотрудник отправляет вопрос клавишей Enter
- **THEN** реплика сразу появляется в ленте, а ответ и состояния агента появляются по мере поступления

## MODIFIED Requirements

### Requirement: Объяснение ответа на вопрос по датасету
Диалог вопросов SHALL показывать блок «Как посчитано» под каждым ответом. Он SHALL содержать источник, расчёт, условия и полноту выдачи понятными словами. Логический SQL к датасету SHALL находиться в закрытом по умолчанию раскрываемом блоке и быть доступен сотруднику без скрытого текста запроса-источника.

#### Scenario: Сотрудник читает ответ
- **WHEN** обычный пользователь получил число или таблицу
- **THEN** он видит объяснение расчёта и может раскрыть логический SQL

#### Scenario: Сотрудник проверяет запрос
- **WHEN** сотрудник хочет посмотреть SQL ответа
- **THEN** он раскрывает «Показать SQL»; остальные ответы остаются свёрнутыми

#### Scenario: Администратор проверяет запрос
- **WHEN** администратор хочет посмотреть SQL ответа
- **THEN** он раскрывает «Показать SQL» в том же блоке, что и сотрудник
