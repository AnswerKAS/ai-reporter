# Proposal: chat-parser-fallback

## Why

Без ключа модели диалог конструктора отвечает отказом, хотя разбор описания по словарю уже работает в отдельном API. Пользователь должен получить раскладку прямо после отправки описания.

## What Changes

`POST /api/reports/chat` автоматически использует детерминированный парсер, если ключ модели отсутствует. Ответ показывает источник `parser`, распознанные поля и непонятые слова. Если показатель не распознан, диалог просит уточнить запрос вместо ошибки 422.

## Capabilities

### Modified Capabilities

- `nl-parsing` — разбор реплики без модели.
- `report-builder` — объяснение режима разбора по словарю в диалоге.
