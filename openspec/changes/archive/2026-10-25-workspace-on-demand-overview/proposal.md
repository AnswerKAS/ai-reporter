# Proposal: workspace-on-demand-overview

## Why

Развёрнутый обзор полей и строк занимает большую часть рабочего окна и отодвигает форму вопроса вниз. Сотрудник должен сам решать, когда посмотреть состав датасета.

## What Changes

- При выборе датасета обзор скрыт; кнопка «Что есть в датасете» находится в блоке «Вопрос к данным».
- Кнопка раскрывает и скрывает обзор. Превью загружается только при раскрытии.
- При смене датасета обзор снова закрыт, а форма вопроса остаётся доступной.

## Capabilities

### Modified Capabilities

- `web-ui` — обзор датасета по кнопке в едином рабочем окне.

## Impact

Меняются только компоненты рабочего окна и его UI-спецификация. API и данные не меняются.
