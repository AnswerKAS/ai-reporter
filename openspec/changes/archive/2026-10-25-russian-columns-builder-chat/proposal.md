# Proposal: russian-columns-builder-chat

## Why

Ответ агента по данным может показывать технические имена SQL-столбцов, а чат конструктора живёт в маленьком модальном окне и выглядит иначе, чем чат вопросов по данным.

## What Changes

- Агент выдаёт русские заголовки таблицы: сперва название поля из настроек датасета, затем комментарий, затем свою подпись для вычисленного столбца.
- Если вычисленный столбец остался без русской подписи, агент получает ошибку и исправляет финальный ответ до отправки пользователю.
- Диалог конструктора становится постоянной панелью с историей, прогрессом, полем ввода и Enter для отправки, как чат вопросов по датасету. Предложенная раскладка и сохранение доступны рядом с диалогом.

## Capabilities

### Modified Capabilities

- `agent` — русские заголовки в ответах по данным.
- `report-builder` — постоянный чат вместо модального окна.

## Impact

Агент `backend/app/agent/runner.py`, компонент `frontend/src/components/builder/ReportChat.tsx`, тесты и спецификации. SQL-запросы и правило чтения остаются прежними; `SELECT *` разрешён.
