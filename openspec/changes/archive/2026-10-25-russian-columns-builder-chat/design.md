# Design: russian-columns-builder-chat

SQL инструмента сохраняет исходные имена столбцов. На финальном шаге агент передаёт `columnLabels` — соответствие имени результата русскому заголовку. Сервер выбирает для каждого столбца настроенное название или комментарий, если оно на русском, иначе подпись агента. Без русской подписи финальный ответ не принимается, а LangGraph возвращает ошибку как наблюдение для исправления. Строки и SQL остаются неизменными.

Чат конструктора использует ту же композицию, что `DatasetQuestionPanel`: заголовок с действиями, прокручиваемая история, видимый ход агента и закреплённый внизу ввод. Панель остаётся смонтированной над шагами конструктора, поэтому переписка не теряется при переходах. Предложение отчёта по-прежнему проходит через `onProposal`, после чего пользователь проверяет предпросмотр и явно сохраняет отчёт.
