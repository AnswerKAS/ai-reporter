# Design

Схема датасета уже содержит имя, тип и комментарий колонки. Генератор рекомендаций использует классификацию типов из `semantic.suggest`, но результат кладёт в `ReportDefinition.fields`, а не в таблицы словаря. Числовая колонка становится показателем с `sum`, дата и строка — разрезами. Если у датасета уже есть словарные показатели, сохраняется прежний путь рекомендаций.

Каждый вариант содержит только свои используемые поля; сервер повторно проверяет колонку при предпросмотре. Клиент при применении предложения добавляет поля в состояние конструктора и включает их в откат. Старые отчёты не мигрируют в этом шаге.
