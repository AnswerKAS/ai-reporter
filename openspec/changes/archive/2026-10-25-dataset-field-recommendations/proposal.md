# Proposal: dataset-field-recommendations

## Why

Подготовленный датасет без записей в «Модели данных» не даёт готовых вариантов отчёта. Сотруднику приходится вручную выбирать каждое поле.

## What Changes

Рекомендации строятся из схемы выбранного датасета, когда у него нет словарных показателей. Вариант содержит собственные поля определения отчёта и проходит существующую проверку построителя. Старые определения со словарными slug продолжают работать.

## Capabilities

### Modified Capabilities

- `report-builder` — варианты по колонкам датасета без глобального словаря.
