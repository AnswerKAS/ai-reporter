## MODIFIED Requirements

### Requirement: План соединения датасетов
Если секции нужны несколько датасетов, построитель SHALL составлять план соединения: базовым берётся датасет метрик, остальные подключаются по связям словаря. При отсутствии прямой связи SHALL искаться кратчайший путь через промежуточные датасеты; если пути нет, сборка SHALL отклоняться. Все датасеты секции SHALL относиться к одному ключу подключения; смешение разных ключей SHALL отклоняться до выполнения SQL.

#### Scenario: Две базы одного типа
- **WHEN** секция требует датасеты из двух подключений PostgreSQL
- **THEN** построитель возвращает понятную ошибку вместо запроса в одну из баз
#### Scenario: Соединение через справочник
- **WHEN** два датасета соединяются через промежуточный датасет того же подключения
- **THEN** построитель включает справочник в план соединения

#### Scenario: Связи нет
- **WHEN** между датасетами нет пути связей
- **THEN** построитель отклоняет секцию до выполнения SQL
