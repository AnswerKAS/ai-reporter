# Design: dataset-connections

`DB_CONNECTIONS` — JSON-объект с ключами `metabase`, `demo` и произвольными ключами источников. Запись содержит `source`, `dsn`, необязательные `title`, `schema`, `sslmode`, `secure`. Секреты не уходят в API. При заданном JSON новые датасеты принимают только `connectionKey` существующего подключения того же типа. Старый DSN остаётся в колонке лишь для переходного периода. CLI делает резервную копию `.env`, записывает JSON и идемпотентно обновляет датасеты. Источники одной секции обязаны иметь один ключ подключения. `POSTGRES_PASSWORD` для начального создания контейнера PostgreSQL — отдельный параметр инфраструктуры.
