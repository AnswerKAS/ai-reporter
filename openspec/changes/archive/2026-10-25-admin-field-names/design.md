# Design: admin-field-names

Техническое имя колонки остаётся идентификатором схемы и SQL. Редактор сохраняет только отображаемое название в `fieldSettings.title`. Для ранее ненастроенного поля с изменённым названием отправляется текущая автоматически определённая роль: серверный контракт требует роль вместе с названием. Для типа, непригодного для отчёта, используется `ignore`. Правка названия не переключает роль в форме.

Список админки открывает существующий `DatasetModal` сразу на вкладке «Поля датасета». После сохранения модалка и список перечитывают датасет. Превью показывает понятное название и техническое имя колонки, чтобы сотрудник узнавал поле, а администратор мог сопоставить его с источником.
