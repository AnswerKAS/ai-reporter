# Proposal: admin-field-names

## Why

Администратор должен задавать сотрудникам понятные названия полей датасета. В существующей вкладке настроек название можно изменить только вместе с ручным выбором роли, а вход в редактор скрыт внутри карточки датасета.

## What Changes

- В списке датасетов админки появляется действие «Переименовать поля», открывающее вкладку полей.
- Название можно изменить независимо от роли, включая поля «Автоматически» и «Не использовать».
- Настроенное название показывается в превью данных с техническим именем рядом.

## Capabilities

### Modified Capabilities

- `datasets` — редактирование отображаемых названий полей в админке.

## Impact

Используются существующие `fieldSettings` и `PUT /api/datasets/{slug}/fields`; новые методы API и миграции не нужны. Меняются редактор полей, вход в него из админки и подписи колонок в превью.
