# Proposal: report-data-preview

## Why

При сборке отчёта сотрудник видит названия показателей, но не может быстро посмотреть, какие поля и значения содержит датасет. Для проверки приходится уходить из конструктора.

## What Changes

В блоке «Отчёт по описанию» появляется кнопка «Посмотреть данные». Она открывает окно со списком доступных датасетов, схемой выбранного датасета и превью его строк. Выбранные для отчёта датасеты показаны первыми. Превью загружается только после нажатия и использует существующий API.

## Capabilities

### Modified Capabilities

- `report-builder` — просмотр исходных данных прямо при сборке отчёта.
