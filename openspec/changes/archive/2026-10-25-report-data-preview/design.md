# Design

Кнопка живёт в `ReportChat`, рядом с описанием отчёта. Окно реализуется отдельным компонентом и использует `GET /api/datasets/{slug}` и существующую таблицу превью. Список датасетов и их схема уже загружены конструктором; отдельный запрос нужен только для строк выбранного датасета. В окне можно переключить датасет, посмотреть названия, типы и роли полей, а также сортировать и фильтровать полученные строки. При закрытии состояние конструктора не меняется.
