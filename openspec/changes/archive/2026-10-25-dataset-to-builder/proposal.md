# Proposal: dataset-to-builder

## Why

Сотрудник может изучить датасет и задать вопрос в его карточке, но для графика должен закрыть окно, перейти в конструктор и заново найти тот же датасет.

## What Changes

В карточке датасета появляется действие «Собрать отчёт». Оно открывает новый конструктор с уже выбранным датасетом. Выбор проходит через адрес `?dataset=<slug>`, чтобы ссылку можно было открыть напрямую; неизвестный slug игнорируется.

## Capabilities

### Modified Capabilities

- `datasets` — переход из карточки датасета к сборке отчёта.
- `report-builder` — начальный выбор датасета из адреса.
