## ADDED Requirements

### Requirement: Предвыбор датасета из адреса
Новый конструктор SHALL принимать `?dataset=<slug>`, проверять slug по загруженному каталогу и отмечать существующий датасет. Неизвестный slug SHALL игнорироваться без ошибочного выбранного поля. При редактировании сохранённого отчёта параметр SHALL игнорироваться.

#### Scenario: Ссылка на новый отчёт по датасету
- **WHEN** пользователь открывает `/builder?dataset=sales_orders`
- **THEN** `sales_orders` уже выбран на шаге «Данные» и его можно снять обычным способом

#### Scenario: Несуществующий датасет
- **WHEN** адрес содержит slug, которого нет в каталоге
- **THEN** конструктор открывается с пустым выбором без ошибки
