# Design

`datasets.schema` остаётся снимком источника: имя, тип, комментарий. Новый JSON-столбец `field_settings` хранит настройки по имени колонки. При `refresh_schema` обновляется только снимок схемы. Для отсутствующей колонки прежняя настройка остаётся сохранённой, но в варианты отчёта не попадает; восстановившаяся колонка снова получит настройку.

Администратор отправляет полную карту настроек через `PUT /api/datasets/{slug}/fields`. Сервер сверяет имена с текущей схемой, роль с закрытым набором, агрегирование с возможностями построителя и нормализует пробелы. Клиент редактирует поля в карточке датасета. Доступный всем `GET /api/datasets` показывает настройки без технических секретов.

`query.interpret` применяет настройки при создании временных кандидатов из схемы. Варианты по-прежнему вкладывают использованные поля в `ReportDefinition.fields`; сохранённые определения не меняются автоматически при последующей правке настроек.
