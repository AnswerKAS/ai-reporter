# Proposal: dataset-fields-in-language-parser

## Why

Рекомендации умеют собирать отчёт по схеме датасета без общего словаря, но запрос словами и диалог по тому же датасету отвечают, что показателей нет. Сотрудник видит разные возможности в соседних действиях конструктора.

## What Changes

Словарь разбора и диалога дополняется полями подготовленных датасетов. Определение, собранное моделью или локальным парсером, включает использованные поля в `fields`; построитель проверяет их по схеме перед выполнением. Существующие словарные отчёты продолжают работать.

## Capabilities

### Modified Capabilities

- `nl-parsing` — разбор описания по полям датасета без общего словаря.
- `report-builder` — диалог возвращает самостоятельное определение с полями.
