## ADDED Requirements

### Requirement: Диалог по схеме выбранного датасета
Диалог конструктора SHALL собирать отчёт по полям подготовленного датасета без записей в общем словаре. Использованные поля SHALL приезжать в полном определении для предпросмотра и сохранения.

#### Scenario: Диалог по датасету без словаря
- **WHEN** автор выбрал датасет без общих показателей и попросил отчёт словами
- **THEN** диалог предлагает раскладку с полями этого датасета, а не отказ из-за пустого словаря
