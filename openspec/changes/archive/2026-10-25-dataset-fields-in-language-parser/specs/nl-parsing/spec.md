## ADDED Requirements

### Requirement: Разбор по полям датасета без общего словаря
Словесный разбор SHALL находить показатели и разрезы из схемы выбранного датасета, если для него не заведён общий словарь. Возвращённое определение SHALL содержать используемые поля в `fields`, чтобы построитель мог его выполнить без глобальных метрик.

#### Scenario: Локальный разбор без модели
- **WHEN** автор выбрал датасет с числовым полем и разрезом и описал отчёт словами при недоступной модели
- **THEN** локальный парсер возвращает секцию и описания использованных полей датасета

#### Scenario: Ответ модели
- **WHEN** модель выбирает поле из схемы датасета
- **THEN** поле проходит сверку со словарём и включается в определение отчёта
