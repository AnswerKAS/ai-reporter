## ADDED Requirements

### Requirement: Точный поиск отчётов по slug
Каталог `GET /api/reports` SHALL принимать повторяемые значения `slug` и возвращать только отчёты с этими slug, доступные текущему пользователю. Поиск SHALL выполняться в SQL вместе с проверкой прав и SHALL не исполнять определения отчётов.

#### Scenario: Среди slug есть удалённый
- **WHEN** клиент запрашивает два существующих отчёта и один удалённый
- **THEN** каталог возвращает только два существующих отчёта

#### Scenario: Один отчёт недоступен
- **WHEN** клиент запрашивает доступный и недоступный ему slug
- **THEN** каталог возвращает только доступный отчёт
