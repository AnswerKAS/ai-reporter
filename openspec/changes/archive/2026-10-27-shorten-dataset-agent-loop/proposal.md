# Proposal: shorten-dataset-agent-loop

## Why

Трейс сессии `0b13622714524d5285fc200cbf3ffd92` показал 18 последовательных вызовов модели за 390,8 секунды. Агент многократно вызывал быстрый SQL-инструмент и исчерпал лимит шагов. Запасная модель начала без проверенных результатов первой попытки и повторила запросы. Даже успешный финальный ответ проходит через второй вызов модели для переформулировки.

## What Changes

- Сохранять проверенные SQL-результаты при переходе на запасную модель и передавать ей краткую выжимку наблюдений.
- После достаточного числа успешных запросов требовать финальный ответ вместо дальнейшего SQL-исследования.
- Отправлять уже проверенный финальный текст модели пользователю без второго вызова модели.

## Capabilities

### Modified Capabilities

- `agent` — бюджет SQL-шагов, перенос наблюдений и завершение ответа.
