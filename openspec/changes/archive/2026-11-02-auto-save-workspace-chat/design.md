## Context
Каталог читает только разговоры с saved_at. Обычная отправка записывает сообщения после успеха агента и не устанавливает saved_at; клиент не обновляет меню.

## Goals / Non-Goals
Сохранять принятые вопросы до расчёта и показывать в истории. Диалог конструктора не меняется.

## Decisions
До запуска агента записывать пару вопрос/ожидаемый ответ одной транзакцией, возвращать id ответа и обновлять его по окончании. Незавершённые ответы исключать из контекста модели. В этой же транзакции заполнять saved_at и название для dataset/workspace, сохраняя ручное имя. Уведомлять меню при подтверждении и завершении потока. URL менять после завершения, чтобы смена адреса не сбрасывала поток.

## Risks / Trade-offs
После перезапуска сервера вопрос может остаться без ответа; обозначать это текстом. Миграция схемы не нужна. Старые скрытые чаты автоматически не восстанавливаются.
