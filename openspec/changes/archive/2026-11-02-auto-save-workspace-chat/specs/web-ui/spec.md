## ADDED Requirements

### Requirement: Автоматическое сохранение первого вопроса по данным
Чат режима «Вопрос по данным» SHALL автоматически появляться в личной истории после первого принятого сообщения, до готовности ответа агента. Название SHALL браться из первого вопроса с пределом 120 символов; заданное пользователем название SHALL сохраняться. Меню SHALL обновляться без перезагрузки страницы. Вопрос SHALL оставаться доступным после перезагрузки, ухода со страницы или ошибки агента; готовый ответ SHALL дополнять этот же вопрос без дублирования. Пустое рабочее окно без отправленных сообщений SHALL не создавать запись истории автоматически.

#### Scenario: Первый вопрос
- **WHEN** сотрудник отправляет первый допустимый вопрос в пустом рабочем окне
- **THEN** чат сразу появляется в меню с названием по вопросу и открывается из истории

#### Scenario: Ответ ещё не готов или агент завершился ошибкой
- **WHEN** сотрудник открывает историю до готовности ответа либо после ошибки
- **THEN** вопрос и прикреплённые датасеты сохраняются, отсутствие готового ответа обозначено

#### Scenario: Продолжение переименованного чата
- **WHEN** сотрудник отправляет следующий вопрос в переименованный чат
- **THEN** название сохраняется, а история содержит каждый вопрос и ответ по одному разу
