# Proposal: isolate-new-report-chat

## Why

Новый отчёт открывает историю предыдущего незавершённого отчёта, потому что диалог с целью `new` находится по последнему обновлению. Сотрудник видит чуждый новому отчёту контекст.

## What Changes

- Каждый вход в создание отчёта начинает пустой черновой чат.
- Продолжение текущего черновика использует его `conversationId`.
- Сохранённый отчёт продолжает открывать свой диалог по slug.

## Capabilities

### Modified Capabilities

- `agent` — изоляция новых черновых диалогов и восстановление сохранённого отчёта.
