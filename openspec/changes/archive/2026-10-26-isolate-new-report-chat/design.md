# Design

Новый черновой диалог создаётся при первом сообщении без `conversationId`. Следующие сообщения того же открытого конструктора передают выданный идентификатор. История для пустой цели `new` без идентификатора не восстанавливается. После сохранения диалог переносится на slug отчёта; при правке история читается по slug. Поведение чата вопросов по датасету не меняется.
