# Design: report-abac

Casbin получает объект пользователя с ID, ролью, группами и объединением личных и групповых меток; объект отчёта содержит автора, назначения и метки. Просмотр разрешён при любом из оснований. Метки отчёта меняет автор или администратор, потому что это расширяет доступ. Администратор один меняет определение и удаляет отчёт. Каталог и фасеты фильтруются SQL до пагинации; тесты сверяют его выдачу с Casbin. Действующие назначения остаются источником данных для ABAC.
