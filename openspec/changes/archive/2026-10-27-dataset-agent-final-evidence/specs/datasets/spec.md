## MODIFIED Requirements

### Requirement: Потоковый ответ по датасету
Система SHALL отправлять промежуточные состояния работы агента и текст ответа потоком и сохранять успешный ход диалога. Таблица ответа и доказательства SHALL содержать последний успешный SQL-результат по каждому прикреплённому датасету. Русские названия требуются для колонок этих результатов; промежуточные запросы не требуют названий для вывода.

#### Scenario: Получение ответа
- **WHEN** сотрудник отправляет вопрос
- **THEN** он видит ход выполнения и текст ответа до завершения всего запроса, а после завершения — таблицу и объяснение

#### Scenario: Разведочный запрос перед итоговым
- **WHEN** агент сначала выполняет разведочный SQL с техническими именами колонок, а затем итоговый SQL по тому же датасету
- **THEN** ответ использует только итоговый результат и не требует русских названий колонок разведочного запроса

#### Scenario: Структурированное русское название
- **WHEN** модель задаёт название колонки объектом с совпадающим `sql_column` и русским полем `Русское название`
- **THEN** ответ показывает русское название этой колонки
