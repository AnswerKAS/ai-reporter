## Решение

Агент по-прежнему видит все SQL-наблюдения и может уточнять запрос. Перед проверкой `final` результаты сворачиваются по `datasetSlug`: последнее успешное выполнение заменяет предыдущее. Ответ, `evidence` и `plan.queries` строятся из этого набора в порядке прикреплённых датасетов.

В `columnLabels` поддерживается обычная строка и объект модели с `sql_column` и `Русское название`. Если `sql_column` не совпадает с ключом колонки, название не применяется.

## Проверка

Регрессионный тест воспроизводит разведочный SQL без русского псевдонима и итоговый SQL с названиями. Отдельный тест проверяет структурированное название.
