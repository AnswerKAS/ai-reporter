Необязательные списки final нормализуются: null и отсутствие означают пустой список; другой тип возвращается модели на исправление. Delta отправляется после подготовки результата целиком. Подписи и названия сохраняются по источнику между исправлениями, но сбрасываются при новом успешном SQL по нему. Проверка собирает все ошибки оформления и передаёт модели список реально полученных колонок. Ограничение SQL сохраняется; ненужный новый SQL на этапе оформления возвращается наблюдением, не выполняется. Итоговая ошибка включает этап и причину, а в трейс попадают причины всех неудачных моделей. Пользовательские события несут понятные message и code без SQL, адресов, ключей и внутренних исключений. Общий сборщик полей сохраняет физический type, дополняет его kind (number/date/string/boolean/other), заголовком и настройками роли. Инструкция предлагает начинать с простых агрегатов и не суммировать идентификаторы или раздувать суммы соединением фактов.
