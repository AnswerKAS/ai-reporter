## Решение

Langfuse запускается отдельным Compose-проектом: web, worker, PostgreSQL, ClickHouse, Redis и MinIO. Web присоединяется к сети приложения; backend обращается к нему по внутреннему имени. Секреты и ключи хранятся в локальных `.env`, исключённых из Git.

Python SDK Langfuse создаёт корневой span на ход каждого агента. CallbackHandler LangChain записывает вызовы модели, а callback LangGraph — шаги графа. Контекст трассировки передаётся в поток, исполняющий `_ask`, чтобы вызовы модели оставались дочерними одного трейса. Идентификатор пользователя и диалога добавляется как атрибут, если он известен.

Без полных `LANGFUSE_PUBLIC_KEY` и `LANGFUSE_SECRET_KEY` трассировка отключена. Сбой экспорта не должен менять ответ приложения.
