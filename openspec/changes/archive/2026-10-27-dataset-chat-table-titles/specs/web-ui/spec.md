## ADDED Requirements

### Requirement: Подписи таблиц ответа по данным
Интерфейс SHALL показывать название результата непосредственно у каждой таблицы в текущем ответе и сохранённой истории. Для сообщений, созданных до появления названий, SHALL показываться запасная подпись.

#### Scenario: Восстановленный диалог
- **WHEN** пользователь открывает сохранённый диалог по данным
- **THEN** названия таблиц отображаются так же, как после получения ответа
