# Design

Финальное действие агента содержит `tableTitles`: соответствие slug датасета и короткого названия результата. Сервер выбирает последний успешный SQL результат каждого источника, как и для `columnLabels`, проверяет непустой русский заголовок и добавляет его в каждый элемент `evidence`. Заголовок основного результата также доступен в `title` ответа для одного источника. Ошибка проверки возвращается агенту как наблюдение.

Ответ целиком сохраняется в существующем JSON payload переписки; миграция БД не нужна. Клиент выводит название как `caption` таблицы, а имя датасета оставляет указанием источника. Для старых записей без названия использует имя источника или нейтральную подпись.
