# Proposal: dataset-chat-table-titles

## Why

Таблицы в ответах чата по данным показывают имена источников и столбцов, но не объясняют, что именно посчитано. При нескольких источниках это мешает быстро понять смысл каждого результата.

## What Changes

- Агент задаёт короткое русское смысловое название последней таблицы каждого прикреплённого датасета.
- Сервер проверяет наличие названий и возвращает пропуск модели на исправление.
- Интерфейс показывает названия над таблицами в новых ответах и сохранённой истории; старые ответы сохраняют понятную запасную подпись.

## Capabilities

### Modified Capabilities

- `agent` — заголовки результатов SQL в ответах по данным.
- `web-ui` — отображение заголовков таблиц чата.
