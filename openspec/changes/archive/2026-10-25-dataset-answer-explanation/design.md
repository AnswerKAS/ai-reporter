# Design: dataset-answer-explanation

`answer.py` строит `explanation` из `clean_plan` после проверки и исполнения запроса. Значения полей берутся из схемы датасета, комментарий колонки служит понятным названием; текст модели не используется для объяснения. Ответ включает отдельные списки расчётов, группировок и условий, сортировку, число показанных строк, фактическое общее число строк, если оно известно, и признак продолжения. Для SQL-источника общий итог без дополнительного запроса неизвестен: исполняется запрос с `LIMIT requested + 1`, лишняя строка не отдаётся клиенту. Для CSV итог известен после чтения файла.

Лимит относится к строкам результата после агрегации, а не к строкам, вошедшим в сумму. Для ответа с несколькими строками «показано» не заменяется на «найдено», если полного числа неизвестно. Сырой SQL и параметры по-прежнему выдаются лишь администратору; UI помещает их в нативный закрытый `<details>` для каждого ответа. Сотруднику доступно одинаковое объяснение для БД и CSV.
