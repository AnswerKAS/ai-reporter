# datasets — реестр источников данных

## ADDED Requirements

### Requirement: Тождество сервера у датасета
Датасет SHALL нести тождество сервера, на котором он лежит: `serverId` —
устойчивый признак четвёрки (тип СУБД, хост, порт, база), и `serverTitle` —
имя сервера для интерфейса. Оба поля SHALL приезжать в выдаче датасетов
любому авторизованному пользователю.

Тождество SHALL считаться **нормализованно**, а не сравнением строк
подключения: синонимы схемы (`postgresql://` и `postgres://`), опущенный порт
при умолчании типа СУБД, регистр хоста и порядок параметров запроса дают
**один** сервер; разные логины к одной базе — тоже один сервер, потому что
сервер определяется адресом, а не тем, кем к нему подключились.

CSV-датасет сервера SHALL не иметь: его источник — файл в хранилище
артефактов. Датасет, чей адрес разобрать не удалось, SHALL остаться без
сервера, а не получить выдуманный.

#### Scenario: Две записи одной базы
- **WHEN** два датасета заведены на `postgresql://a:1@db:5432/x` и `postgres://b:2@DB/x`
- **THEN** у обоих один `serverId` — это одна база на одном сервере

#### Scenario: Разные базы одного сервера
- **WHEN** два датасета лежат на одном хосте, но в разных базах
- **THEN** `serverId` у них разные: джойн между ними в SQL не спускается

#### Scenario: Датасет из файла
- **WHEN** датасет загружен из CSV
- **THEN** сервера у него нет, и в отборе он попадает в отдельный вариант, а не к какому-нибудь серверу

### Requirement: Адрес сервера не выходит за пределы бэкенда
`serverTitle` SHALL называть сервер, не раскрывая его адреса: обычный
пользователь видит тип СУБД и порядковый номер сервера («PostgreSQL ·
сервер 2»). Хост, порт и имя базы SHALL подставляться в имя только
администратору.

Номер SHALL быть устойчивым: порядок задаёт самый ранний датасет сервера,
поэтому заведение нового датасета или нового сервера не перенумеровывает уже
показанные.

Правило то же, что и для текстов ошибок источника: адреса, логины и пароли не
выводятся в API и UI. Для отбора датасетов по серверу номера достаточно.

#### Scenario: Пользователь смотрит на карточку датасета
- **WHEN** датасет открывает пользователь без прав администратора
- **THEN** он видит «PostgreSQL · сервер 2», но не хост, порт и базу

#### Scenario: Администратор смотрит на тот же датасет
- **WHEN** тот же датасет открывает администратор
- **THEN** в имени сервера виден адрес — ему решать, куда смотрит датасет
