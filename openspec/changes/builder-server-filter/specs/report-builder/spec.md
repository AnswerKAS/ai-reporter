# report-builder — конструктор отчётов

## MODIFIED Requirements

### Requirement: Шаг «Данные» выдерживает тысячу датасетов
Плитка датасетов SHALL давать сузить выбор: поиском по названию, slug'у,
описанию, имени таблицы и именам полей, фильтрами по источнику и статусу
подключения с несколькими выбранными значениями сразу и счётчиками у
вариантов, отбором по **серверу** и быстрыми отборами «выбранные»,
«связанные с выбранным» и «со словарём».

Отбор по серверу SHALL быть выбором одного значения из списка, а не полосой
чипов: серверов на установке бывают десятки, и полосой они не помещаются.
Варианты SHALL быть сгруппированы по типу СУБД, нести счётчик датасетов и
иметь вариант «все серверы»; датасеты без сервера (CSV) SHALL собираться в
отдельный вариант.

Карточка датасета SHALL называть свой сервер там же, где источник и таблицу.

Порядок карточек SHALL быть осмысленным, а не порядком реестра: сначала
выбранные, затем связанные с выбранными, дальше по алфавиту. Выбранные
датасеты SHALL быть видны всегда, даже когда отбор их скрывает.

Плитка SHALL рисовать ограниченное число карточек за раз, показывать, сколько
показано из скольких, и догружать остальные по требованию: тысяча карточек в
разметке делает шаг неотзывчивым, а глазами всё равно не читается.

#### Scenario: Тысяча датасетов
- **WHEN** в реестре больше тысячи датасетов
- **THEN** шаг «Данные» рисует первую порцию карточек, называет общее число и догружает остальные по кнопке

#### Scenario: Поиск по имени колонки
- **WHEN** автор ищет `revenue`
- **THEN** в плитке остаются датасеты с такой колонкой, даже если в названии датасета этого слова нет

#### Scenario: Выбранное не теряется
- **WHEN** отбор скрывает уже выбранный датасет
- **THEN** он всё равно виден отдельной строкой над плиткой и его можно снять

#### Scenario: Только то, с чем джойнится
- **WHEN** автор выбрал датасет и включает отбор «связанные с выбранным»
- **THEN** в плитке остаются датасеты, достижимые по связям, — те, что могут оказаться с ним в одной секции

#### Scenario: Десять серверов PostgreSQL
- **WHEN** автору нужны витрины с одного сервера, а серверов PostgreSQL десять
- **THEN** он выбирает сервер в списке, и в плитке остаются только его датасеты — фильтр по типу СУБД такой выборки не давал

#### Scenario: Датасеты из файлов
- **WHEN** автор выбирает вариант «без сервера»
- **THEN** в плитке остаются CSV-датасеты, у которых сервера нет
