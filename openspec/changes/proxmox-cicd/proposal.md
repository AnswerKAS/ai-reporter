# Автоматическая доставка на Proxmox

## Почему

Приложение уже работает в LXC 111, но код на сервер переносился вручную.
GitHub-hosted runner не достигает приватной сети Proxmox, а публичный SSH-порт
закрыт. Нужна доставка после успешных проверок без открытия SSH и без секретов
сервера в GitHub.

## Что меняется

- GitHub Actions проверяет каждый push в `main`: тесты бэкенда, lint и сборку
  фронтенда, валидацию OpenSpec.
- Сервис в LXC 111 опрашивает `main` и открытый GitHub Actions API. Он доставляет
  только точный коммит, для которого проверка завершилась успешно.
- Доставка сохраняет серверные `.env` и Docker-тома, проверяет здоровье приложения
  и восстанавливает прежний код при неудаче.
- Первый запуск не перезаписывает существующий серверный код молча.

## Вне области

Схема PostgreSQL и данные отчётов, Langfuse и Garage остаются на текущих
серверах. Автоматизация не управляет VPN-профилем и сертификатами NPM.
