# Дизайн

GitHub Actions — только проверка, без self-hosted runner и секретов: репозиторий
публичный, а LXC 111 находится за NAT. В LXC 111 systemd timer запускает
`deploy/proxmox_deploy.py`. Скрипт получает SHA ветки `main` из Git, затем
проверяет по API GitHub, что workflow `ci.yml` для этого SHA и события `push`
завершился успешно. Другой SHA, ручной запуск workflow или неуспешная проверка
не дают права на доставку.

Скрипт запускается под root внутри LXC 111. Он берёт файловую блокировку,
разворачивает проверенный Git-коммит во временный каталог, сохраняет копию
текущего исходного кода и выполняет rsync с явным исключением серверных `.env`,
локальных каталогов и Docker-томов. Compose собирает и поднимает `backend` и
`frontend` в существующем проекте `ai-reporter`; Langfuse не перезапускается.
После проверки `/api/health` скрипт записывает доставленный SHA. При ошибке
возвращает прежний код и пытается восстановить прежние контейнеры.

Таймер продолжает опрос после ошибки. Первую доставку блокирует отсутствие
файла с зафиксированной базовой версией на сервере: оператор сначала сверяет
серверный код с `main` и выбирает, какое состояние сделать исходным. Этот
барьер нужен, поскольку на сервере сейчас есть изменения, отсутствующие в Git.
