## ADDED Requirements

### Requirement: Согласованность окна детализации при смене источника
Окно SHALL оставлять видимыми только строки выбранного источника. Ответ более раннего запроса SHALL игнорироваться после смены источника или закрытия окна.

#### Scenario: Быстрое переключение источника
- **WHEN** сотрудник выбирает другой датасет до завершения загрузки первого
- **THEN** окно показывает только строки последнего выбранного датасета

#### Scenario: Детализация SQL-блока
- **WHEN** сотрудник открывает детализацию элемента SQL-блока
- **THEN** окно называет строки исходными строками датасета и показывает оговорку о том, что условия SQL-блока не применены
