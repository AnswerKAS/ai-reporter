# Proposal: report-drilldown-per-element

## Why

Клик по карточке KPI или серии графика передаёт только разрез точки. Если секция содержит показатели разных датасетов, детализация выбирает первый источник секции даже для элемента второго источника. При переключении источников во время загрузки возможен показ устаревшей страницы.

## What Changes

- Передавать ключ выбранного показателя из KPI, серии графика и ячейки таблицы в запрос детализации.
- Ограничивать список источников теми датасетами, из которых получен выбранный показатель.
- Проверять, что общий запрос сырых данных указывает датасет самого отчёта.
- Игнорировать устаревший ответ при смене источника в окне детализации.
- Проверить представительные секции каждого вида на реальном тестовом отчёте.

## Capabilities

### Modified Capabilities

- `reports` — выбор сырья по конкретному показателю.
- `web-ui` — корректное направление кликов каждого элемента и устойчивость окна к смене источника.
