# artifacts Specification

## Purpose
Возможность описывает хранение файловых артефактов (загруженные CSV-датасеты) через единый фасад хранилища с переключаемым режимом.

## Requirements

### Requirement: Фасад хранилища
Все обращения к артефактам SHALL выполняться через фасад `services/storage.py` (save/load/exists/delete/path/materialize) с выбором реализации по переменной `ARTIFACTS_STORAGE`; реализация `s3` зарезервирована, сейчас доступен `local`.

#### Scenario: Единая точка доступа
- **WHEN** реестр датасетов работает с файлами загруженных CSV
- **THEN** они обращаются только к фасаду, а не к файловой системе напрямую

### Requirement: Local-режим
В режиме `local` артефакты SHALL храниться в каталоге из `ARTIFACTS_DIR` (по умолчанию `backend/artifacts`) с лэйаутом `datasets/<slug>/data.csv`. Переключение каталога не требует миграции данных.

#### Scenario: Кастомный каталог
- **WHEN** бэкенд запущен с `ARTIFACTS_DIR=/var/lib/ai-reporter/artifacts`
- **THEN** CSV-файлы создаются и читаются из указанного каталога

### Requirement: Удаление артефактов владельца
При удалении датасета SHALL удаляться весь каталог его артефактов, чтобы на диске не оставалось файлов без владельца.

#### Scenario: Удаление CSV-датасета
- **WHEN** администратор удаляет датасет-CSV
- **THEN** каталог `datasets/<slug>` с загруженным файлом удаляется
