# Скилл: Сводка по менеджерам

## Цель
Сформировать периодический отчёт по работе менеджеров: ключевые метрики
эффективности, динамика по неделям, структура нагрузки и рейтинг сотрудников.

## Источник данных
Витрина `manager_stats` в Postgres/ClickHouse. Доступ задаётся через переменную
окружения `DATABASE_URL` (DSN). Если она не задана или подключение недоступно —
использовать синтетические данные с теми же полями.

Минимальный набор полей:
- `manager_id`
- `manager_name` (Ф.И.О. менеджера)
- `team` (команда/отдел)
- `tasks_total` (количество задач)
- `tasks_done` (завершено задач)
- `revenue` (выручка/продажи на менеджера)
- `avg_response_min` (среднее время ответа, минуты)
- `timestamp` (дата/время)

## Что должно быть в отчёте
1. Блок обзора (markdown): период, источник.
2. KPI-карточки:
   - Завершено задач (number)
   - Эффективность / доля выполненных (percent)
   - Выручка на менеджера (money)
   - Среднее время ответа (number, минуты)
   Каждая — с изменением к прошлому периоду (delta).
3. График: динамика задач и выручки по неделям (line).
4. График: завершённость задач по командам (bar).
5. График: структура выручки по командам (pie).
6. Таблица: рейтинг менеджеров (ранг, менеджер, команда, задачи всего,
   завершено, эффективность, выручка, среднее время ответа).

## Формат вывода
Скрипт `report.py` при запуске с аргументом `--output <путь>` записывает
JSON-спеку отчёта в формате ReportSpec (схема описана агенту отдельно).

## Параметры и фильтры
- `period` — месяц в формате YYYY-MM (по умолчанию: последние 35 дней).
  Объявить фильтром `{"key": "period", "kind": "text"}`: пусто — последние 35 дней.
- `team` — фильтр по команде (например `sales`); пусто — все команды.
  Объявить фильтром `{"key": "team", "kind": "select", "options": [...]}`
  (options из DISTINCT team).
- `tasks_total` — фильтр «задач от»: порог по количеству задач, поле ввода
  числа, по умолчанию 0 (без ограничения). Объявить фильтром
  `{"key": "tasks_total", "kind": "number", "default": 0}`:
  FILTER_TASKS_TOTAL приводить к числу; 0/пусто — без ограничения.
