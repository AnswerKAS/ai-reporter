# Скилл: SLA поддержки

## Цель
Отчёт по скорости реакции поддержки: время ответа, выполнение задач
и нагрузка внутри команды support по дням/неделям.

## Источник данных
Таблица `manager_stats` в ClickHouse (база из `DATABASE_URL`). Использовать
только строки `team = 'support'`. Если DSN не задан или подключение
недоступно — синтетические данные с теми же полями.

Поля таблицы:
- `date` (Date)
- `manager_name` (String)
- `team` (String)
- `tasks_total` (UInt32)
- `tasks_done` (UInt32)
- `revenue` (Float64)
- `avg_response_min` (Float64)

## Что должно быть в отчёте
1. Блок обзора (markdown): период, источник.
2. KPI-карточки (с delta к предыдущей половине периода):
   - Среднее время ответа (number, минуты) — ниже лучше
   - Завершено задач (number)
   - Эффективность (percent)
   - Выручка поддержки (money)
3. График (line): среднее время ответа и завершённые задачи по дням.
4. График (bar): эффективность по менеджерам поддержки, %.
5. Таблица: менеджеры поддержки (менеджер, задач всего, завершено,
   эффективность, среднее время ответа).

## Фильтры
Объявить в спеке фильтр `manager` (select) по `manager_name`
из DISTINCT (только support-менеджеры). Применять через
`FILTER_MANAGER` с проверкой по options.

## Формат вывода
Скрипт `report.py` при запуске с аргументом `--output <путь>` записывает
JSON-спеку отчёта в формате ReportSpec (схема описана агенту отдельно).

## Параметры
- `period` — месяц в формате YYYY-MM (по умолчанию: последние 35 дней).
