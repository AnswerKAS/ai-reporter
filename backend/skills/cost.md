# Скилл: Средняя стоимость заявки

## Цель
Отчёт по экономике обработки заявок: средняя стоимость на заявку
(выручка / поступившие заявки), динамика по неделям, разрезы по командам
и менеджерам.

## Источник данных
Таблица `manager_stats` в ClickHouse (база из `DATABASE_URL`). «Заявка» —
значение `tasks_total` (поступившие заявки за день менеджера). Если DSN не
задан или подключение недоступно — синтетические данные с теми же полями.

Поля таблицы:
- `date` (Date)
- `manager_name` (String)
- `team` (String)
- `tasks_total` (UInt32) — поступившие заявки
- `tasks_done` (UInt32) — обработанные заявки
- `revenue` (Float64) — выручка, рубли
- `avg_response_min` (Float64)

## Что должно быть в отчёте
1. Блок обзора (markdown): период, источник, формула метрики.
2. KPI-карточки (с delta к предыдущей половине периода):
   - Средняя стоимость на заявку (money) = sum(revenue) / sum(tasks_total)
   - Выручка (money)
   - Заявок поступило (number)
   - Обработано заявок (number)
3. График (line): средняя стоимость заявки по неделям.
4. График (bar): средняя стоимость заявки по командам.
5. График (pie): структура выручки по командам.
6. Таблица: по менеджерам (менеджер, команда, заявок поступило,
   обработано, выручка, средняя стоимость заявки).

## Фильтры
Объявить в спеке фильтры `team` и `manager` (select) из DISTINCT-запросов.
Применять через `FILTER_TEAM` / `FILTER_MANAGER` с проверкой значения
по списку options (защита от инъекций). Пустая строка = фильтр выключен.

## Формат вывода
Скрипт `report.py` при запуске с аргументом `--output <путь>` записывает
JSON-спеку отчёта в формате ReportSpec (схема описана агенту отдельно).

## Параметры
- `period` — месяц в формате YYYY-MM (по умолчанию: последние 35 дней).
