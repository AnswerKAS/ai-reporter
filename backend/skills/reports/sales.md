# Скилл: Отчет по отстающим

## Датасеты: sales_orders

## Цель
Оперативный отчёт для руководителя продаж: показывает «отстающих» за период —
худший день по выручке, сумму продаж, город и категории с наименьшими
продажами, а также динамику выручки по датам в разрезах городов и категорий.

## Источник данных
Датасет `sales_orders` (источник: ClickHouse, таблица `sales_orders`). Доступ —
через переменные окружения `DATASET_SALES_ORDERS_DSN` / `DATABASE_URL`. Если
DSN не задан или подключение недоступно — использовать синтетические данные
с теми же полями.

Разреза «сотрудник/менеджер» в данных НЕТ: отчётов по сотрудникам не строить,
полей-заглушек не придумывать. Возвраты (`is_return = 1`) из всех агрегатов
исключить.

Поля таблицы:
- `order_date` (Date — дата заказа)
- `region` (LowCardinality(String) — город/регион)
- `category` (LowCardinality(String) — категория товара)
- `revenue` (Float64 — выручка)
- `orders` (UInt32 — число заказов)
- `is_return` (UInt8 — признак возврата, 1 = возврат)

## Что должно быть в отчёте
1. kpi «Отстающие за период» — три плитки:
   - «Худший день» — дата `order_date` с минимальной суммой `revenue`
     за период; значение — дата, подпись — выручка этого дня (целые рубли);
   - «Сумма продаж» — суммарный `revenue` за период (целые рубли);
   - «Худший город» — `region` с минимальной суммой `revenue` за период;
     значение — название региона, подпись — его выручка.
2. chart «Динамика выручки по датам» — line, X = `order_date` (по дням),
   Y = сумма `revenue` за день; одна серия по всему периоду, без разбивки.
3. chart «Выручка по городам по датам» — line с разбивкой по `region`:
   X = `order_date`, по одной серии на регион (в легенде — название региона),
   Y = сумма `revenue`; не более 8 серий — остальные регионы свернуть
   в серию «Прочие» по суммарной выручке.
4. chart «Выручка по категориям по датам» — line с разбивкой по `category`:
   X = `order_date`, по одной серии на категорию, Y = сумма `revenue`.
5. table «Категории с самыми низкими продажами по дням» — строки на уровне
   `order_date` × `category`; колонки: Дата (`order_date`), Категория
   (`category`), Выручка (сумма `revenue`, целые рубли), Заказы (сумма
   `orders`); сортировка по возрастанию выручки (худшие комбинации сверху);
   LIMIT 30.

## Формат вывода
Скрипт `report.py` при запуске с аргументом `--output <путь>` записывает
JSON-спеку отчёта в формате ReportSpec (схема описана агенту отдельно).

## Параметры
- `period` — месяц в формате YYYY-MM (по умолчанию: текущий месяц).
