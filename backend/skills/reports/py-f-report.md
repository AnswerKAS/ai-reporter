# Скилл: Отчет по полям

## Датасеты: tast-field-details

## Цель
Анализ заполнения полей в задачах Pyrus и структуры форм:
1. Заполненность полей по каждой задаче.
2. Использование полей типа `catalog` в разрезе форм.
3. Поиск полей с одинаковыми названиями внутри формы (без учёта регистра).

## Источник данных
Датасет: **tast-field-details** — детали по задачам в Pyrus (postgres, таблица `public.pyrus_form_fields`).

| Поле | Тип | Описание |
|---|---|---|
| form_id | bigint | Идентификатор формы |
| task_id | bigint | Идентификатор задачи |
| field_id | bigint | Идентификатор поля |
| row_id | bigint | Идентификатор строки (для табличных/повторяющихся полей) |
| field_name | text | Название поля |
| field_type | text | Тип поля |
| field_value | text | Значение поля |

## Что должно быть в отчёте
1. **Таблица «Заполненность полей по задачам»**: по каждой задаче (`task_id` в разрезе `form_id`) — общее количество строк с полями и количество заполненных (условие заполненности: `field_value IS NOT NULL AND TRIM(field_value) <> ''`), а также процент заполненности. Для табличных полей учитывать связку `field_id + row_id`.
2. **График «Поля типа catalog по формам»**: столбчатая диаграмма — количество полей с `field_type = 'catalog'` для каждой формы (`form_id`). Показывать только формы, где такие поля есть; сортировка по убыванию количества.
3. **Таблица «Дубли названий полей»**: в разрезе каждой формы (`form_id`) — названия полей, встречающиеся более одного раза без учёта регистра (группировка по `form_id` + `lower(field_name)`), с количеством вхождений. Показывать только дубли (число вхождений > 1), сортировка: `form_id`, затем по убыванию числа вхождений.

## Формат вывода
- **Секция 1** — markdown-таблица: Форма (`form_id`), Задача (`task_id`), Всего полей, Заполнено полей, % заполненности. Сортировка по убыванию % заполненности. Под таблицей — итоговая строка по всем задачам.
- **Секция 2** — столбчатая диаграмма (bar chart): ось X — `form_id`, ось Y — количество полей типа `catalog`. Под диаграммой — сводная таблица: `form_id`, количество catalog-полей.
- **Секция 3** — markdown-таблица: Форма (`form_id`), Название поля (в нижнем регистре), Число вхождений. Если дублей нет — вывести «Дубли названий полей не обнаружены».
- Каждая секция снабжается кратким пояснением; фильтры, применённые к отчёту, указываются в начале отчёта.

## Параметры
| Параметр | Поле датасета | Описание | Обязательный | По умолчанию |
|---|---|---|---|---|
| field_type | field_type | Тип поля для фильтрации (например, `catalog`) | Нет | Все типы |
| form_id | form_id | Номер формы | Нет | Все формы |

## Фильтры
- **field_type** — точное совпадение со значением поля `field_type`. Если не задан — не применяется.
- **form_id** — точное совпадение с `form_id`. Если не задан — не применяется.
- Оба фильтра применяются ко всем трём секциям отчёта до агрегации.
