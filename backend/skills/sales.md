# Скилл: Сводка продаж по регионам

## Цель
Сформировать ежемесячный отчёт по продажам: ключевые метрики, динамика
выручки по неделям, структура продаж по категориям и регионам.

## Источник данных
Витрина `sales_orders` в Postgres/ClickHouse. Доступ задаётся через переменную
окружения `DATABASE_URL` (DSN). Если она не задана или подключение недоступно —
использовать синтетические данные с теми же полями.

Минимальный набор полей:
- `order_id`
- `region` (имя региона)
- `category` (категория товара)
- `revenue` (выручка заказа)
- `orders` (количество заказов)
- `timestamp` (дата/время заказа)

## Что должно быть в отчёте
1. Блок обзора (markdown): период, источник.
2. KPI-карточки:
   - Выручка (money)
   - Количество заказов (number)
   - Средний чек (money)
   - Доля возвратов (percent)
   Каждая — с изменением к прошлому периоду (delta).
3. График: динамика выручки и заказов по неделям (line).
4. График: продажи по регионам (bar).
5. График: структура выручки по категориям (pie).
6. Таблица: топ-категории (ранг, категория, выручка, заказы, доля, средний чек).

## Формат вывода
Скрипт `report.py` при запуске с аргументом `--output <путь>` записывает
JSON-спеку отчёта в формате ReportSpec (схема описана агенту отдельно).

## Параметры
- `period` — месяц в формате YYYY-MM (по умолчанию: текущий месяц).
