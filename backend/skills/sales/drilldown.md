# Скилл: Выручка по регионам с детализацией

## Датасеты: sales_orders, manager_stats

## Цель
Отчёт из двух графиков: выручка по городам с детализацией по клику
и комбинированный график «категории и сотрудники» по неделям.
Клик по столбцу первого графика открывает детализацию — разбивку
выручки по дням и категориям внутри города.

## Источник данных
Витрины `sales_orders` (продажи) и `manager_stats` (сотрудники) в
ClickHouse. Доступ задаётся через переменную окружения `DATABASE_URL`
(DSN). Если она не задана или подключение недоступно — использовать
синтетические данные с теми же полями.

Поля таблицы `sales_orders`:
- `order_date` (Date)
- `region` (город/регион)
- `category` (категория товара)
- `revenue` (выручка заказа, рубли)
- `orders` (количество заказов)
- `is_return` (1 если заказ возвращён)

Поля таблицы `manager_stats`:
- `date` (Date)
- `manager_name` (сотрудник)
- `team` (подразделение)
- `tasks_total`, `tasks_done` (задач всего/закрыто)
- `revenue` (выручка)
- `avg_response_min` (среднее время ответа, минуты)

## Фильтры
- `region` — «Город», kind: select, options из
  `SELECT DISTINCT region FROM sales_orders ORDER BY region`.
- Значение приходит в переменной `FILTER_REGION`; применять как
  `WHERE region = '<значение>'` к запросам по `sales_orders`
  (значение проверять по options — защита от инъекций). Пустая строка =
  фильтр выключен.
- На `manager_stats` фильтр не влияет (там нет поля региона) — заявляй
  это в description отчёта.
- Метаданные фильтра объявить в корне спеки: `filters: [{"key": "region",
  "label": "Город", "kind": "select", "options": [...]}]`.

## Что должно быть в отчёте
Ровно две секции, обе — графики:

1. График (kind: bar) «Выручка по городам»:
   - данные: выручка по городам (xKey: `region`, серия `revenue`, money);
   - сортировка по убыванию выручки.
   Каждая точка графика должна иметь детализацию — поле `detail`
   внутри секции chart:

   ```json
   "detail": {
     "title": "Детализация: {point}",
     "columns": [
       {"key": "order_date", "header": "Дата", "format": "date"},
       {"key": "category", "header": "Категория"},
       {"key": "revenue", "header": "Выручка", "format": "money"},
       {"key": "orders", "header": "Заказы", "format": "number"}
     ],
     "rowsBy": {
       "Москва": [
         {"order_date": "2026-08-01", "category": "Электроника", "revenue": 120000, "orders": 3}
       ]
     }
   }
   ```

   Требования к `detail`:
   - `title` — шаблон с плейсхолдером `{point}`: фронт подставит имя точки.
   - `columns` — колонки таблицы детализации.
   - `rowsBy` — словарь: ключ — точное значение `region` из `data` точки,
     значение — строки детализации (агрегат по дню и категории:
     `order_date`, `category`, `sum(revenue)`, `sum(orders)`;
     не более 15 строк на город, сортировка по убыванию выручки).
   - Ключи `rowsBy` обязаны совпадать со значениями `region` в `data`
     символ в символ — по ним фронт находит строки по клику.
   - Значение фильтра `region` применяется и к детализации.

2. Комбинированный график (kind: combo) «Категории и сотрудники по неделям»:
   - xKey: `week` — неделя (первый день недели, YYYY-MM-DD), сортировка
     по возрастанию;
   - столбцы — выручка по категориям: одна серия на категорию
     (`type: "bar"`), key = имя категории, топ-5 категорий по выручке
     за период, данные из `sales_orders` (с учётом фильтра `region`);
   - линии — сотрудники: закрытые задачи по неделям (`tasks_done`,
     `type: "line"`), key = имя сотрудника, топ-3 сотрудника по закрытым
     задачам, данные из `manager_stats` (без учёта фильтра);
   - каждая точка `data` содержит ключ `week` плюс все ключи серий
     одновременно (отсутствующие значения — 0);
   - единицы разные (рубли и задачи) — поэтому столбцы рисуются на левой
     оси, линии на правой (фронт делает это сам для kind: combo).

Других секций (markdown/kpi/table) в отчёте быть не должно.

## Формат вывода
Скрипт `report.py` при запуске с аргументом `--output <путь>` записывает
JSON-спеку отчёта в формате ReportSpec (схема описана агенту отдельно).

## Параметры
- `period` — месяц в формате YYYY-MM (по умолчанию: текущий месяц).
