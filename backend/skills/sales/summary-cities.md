# Скилл: Сводка по городам

## Датасеты: sales_orders

## Цель
Отчёт для руководителя продаж: выручка и количество заказов по городам за выбранный период. Помогает быстро увидеть города-лидеры по выручке и средний чек.

## Источник данных
Витрина `sales_orders` в ClickHouse. Доступ — переменная окружения
`DATABASE_URL` (DSN). Если DSN не задан или подключение недоступно —
использовать синтетические данные с теми же полями.

Поля таблицы:
- `order_date` (Date — дата заказа);
- `region` (LowCardinality(String) — город/регион продажи);
- `category` (LowCardinality(String) — категория товара);
- `revenue` (Float64 — выручка заказа, рубли);
- `orders` (UInt32 — количество заказов);
- `is_return` (UInt8 — признак возврата; в отчёте учитываются все заказы, фильтр по возвратам не применяется).

## Что должно быть в отчёте
1. kpi «Выручка за период»: сумма `revenue` по всем заказам за период; формат money (целые рубли).
2. kpi «Средний чек»: сумма `revenue` делить на сумму `orders` за период; формат money (целые рубли).
3. chart (kind: `bar`) «Выручка по городам»: по каждому городу (`region`) — суммарная выручка; сортировка по убыванию выручки (первый — город с максимумом); xKey — `region`, одна серия `Выручка` по `revenue`; ограничение топ-15 городов.
4. table «Города»: колонки `Город`, `Выручка`, `Заказы`, `Средний чек`; одна строка на город (`region`), сортировка по убыванию выручки, LIMIT 15; выручка и средний чек — money, заказы — целое число.

## Формат вывода
Скрипт `report.py` при запуске с аргументом `--output <путь>` записывает
JSON-спеку отчёта в формате ReportSpec (схема описана агенту отдельно).

## Параметры
- `period` — месяц в формате YYYY-MM (по умолчанию: текущий месяц); выборка — заказы, у которых `order_date` попадает в этот месяц.
