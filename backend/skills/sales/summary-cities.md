# Скилл: Сводка по городам

## Датасеты: sales_orders

## Цель
Сводка продаж по городам за период: выручка, количество заказов и средний чек в KPI-карточках плюс bar-график топ-15 городов по выручке. Для руководителя продаж, который быстро оценивает географию выручки.

## Источник данных
Датасет `sales_orders` (источник: ClickHouse, таблица `sales_orders`). Доступ — через переменные окружения `DATASET_SALES_ORDERS_DSN` / `DATABASE_URL`. Если DSN не задан или подключение недоступно — использовать синтетические данные с теми же полями.

Поля таблицы:
- `order_date` (Date — дата заказа)
- `region` (LowCardinality(String) — город; именно это поле используется как разрез «город»)
- `category` (LowCardinality(String) — категория товара)
- `revenue` (Float64 — выручка, рубли)
- `orders` (UInt32 — количество заказов)
- `is_return` (UInt8 — признак возврата: 1 = возврат)

## Что должно быть в отчёте
1. KPI-карточки (секция kpi, три карточки) по данным за выбранный период (`period`):
   - «Выручка» — сумма `revenue` по всем строкам периода (money, целые рубли);
   - «Заказы» — сумма `orders` по всем строкам периода (целое число);
   - «Средний чек» — сумма `revenue` / сумма `orders` за период (money, целые рубли; округление в скрипте, форматирование — на фронте).
2. Bar-график (секция chart, kind `bar`) «Выручка по городам»:
   - агрегация — сумма `revenue` по `region` за период;
   - сортировка по убыванию выручки;
   - только топ-15 городов (LIMIT 15);
   - xKey — город (значение `region`), yKey — выручка.

## Формат вывода
Скрипт `report.py` при запуске с аргументом `--output <путь>` записывает JSON-спеку отчёта в формате ReportSpec (схема описана агенту отдельно).

## Параметры
- `period` — месяц в формате YYYY-MM (по умолчанию: текущий месяц); все секции считаются по строкам с `order_date` внутри этого месяца.
