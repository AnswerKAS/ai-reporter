# Скилл: Мой пайрус отчет

## Датасеты: pyrus

## Цель
Показать руководителю, сколько всего форм заведено в Пайрус, и на графике — в какие даты они создавались.

## Источник данных
Датасет `pyrus` (источник: PostgreSQL, таблица `public.pyrus_general`). Подключение — через переменную окружения `DATASET_PYRUS_DSN` (драйвер psycopg). Если DSN не задан или подключение недоступно — использовать синтетические данные с теми же полями (разумное распределение `created_at` за последние ~180 дней).

Поля таблицы:
- `form_id` (bigint — идентификатор формы)
- `form_name` (text — название формы)
- `deleted_or_closed` (boolean — признак удалённой/закрытой формы)
- `created_at` (timestamp with time zone — дата и время создания формы)
- `updated_at` (timestamp with time zone — дата и время последнего обновления)

## Что должно быть в отчёте
1. KPI-секция «Всего форм»: общее количество форм — `COUNT(*)` по таблице (каждая строка = одна форма; если `form_id` дублируется, считать `COUNT(DISTINCT form_id)`). Учитываются все формы, включая `deleted_or_closed = true`, так как запрошено «всего». Формат — целое число.
2. Chart-секция «Создание форм по датам»: линейный график (kind `line`). Ось X — дата создания `created_at::date` в формате `YYYY-MM-DD`; ось Y — количество форм, созданных в эту дату (`COUNT(*)` c группировкой по дате, `created_at IS NULL` — пропускать). Сортировка по дате по возрастанию, без лимита точек.

## Формат вывода
Скрипт `report.py` при запуске с аргументом `--output <путь>` записывает JSON-спеку отчёта в формате ReportSpec (схема описана агенту отдельно). Разрешены stdlib и psycopg.
